# Blocade

[Скачать APK](https://github.com/murtmarsel/Blocade-Releases/releases/tag/v1.3.2-preview)

Клиент управляемого устройства, Android 7+. Исходники хранятся в отдельном приватном репозитории.

Публичный APK не содержит паролей, токенов или идентификатора тестового телефона. Для подключения отсканируйте одноразовый QR администратора из Blocade Управление. После разрешений можно дополнительно привязать управляющего или пропустить этот шаг.

Для обновления существующего устройства создайте QR с его текущим ID в административной панели приложения, чтобы сохранить карточку устройства. Для нового устройства оставьте поле ID пустым.

Предварительный выпуск. Проверка новой версии на физическом телефоне ещё не завершена.
